# API contract tối thiểu

Base URL: `http://localhost:3001/api`

## Telemetry
POST `/telemetry`
```json
{
  "device_id":"ESP32_A101",
  "room":"A101",
  "temperature":30.2,
  "humidity":65,
  "occupancy":true,
  "light_raw":399,
  "light_percent":90,
  "timestamp":"2026-10-14T14:00:00+07:00"
}
```

## Ingestion error
POST `/ingestion-errors` với cùng sensor fields và `error_reason`.

## Manual command
POST `/commands/manual`
```json
{ "device_id":"ESP32_A101", "command_type":"FAN", "action":"ON" }
```
Backend gọi n8n webhook `device-command`.

## Incident
POST `/incidents`
```json
{ "room":"A101", "device_id":"ESP32_A101", "incident_type":"HIGH_TEMP", "severity":"HIGH", "message":"Temperature exceeded threshold" }
```
`severity` accepts `LOW`, `MEDIUM`, `HIGH`, `INFO`, `WARNING`, or `CRITICAL`. `room`, `incident_type`, and a message of at least 3 characters are required.

## Daily and weekly reports
GET `/reports/daily?room=A101` returns today's incident counts by status/severity and device health counts.
GET `/reports/weekly?room=A101` returns the last 7 days of incident counts and an optimization recommendation. A stored `WEEKLY` or `WEEKLY_OPTIMIZATION` report recommendation takes precedence over the system-generated summary.
POST `/reports` stores a report generated by an AI/n8n workflow:
```json
{
  "report_type":"WEEKLY_OPTIMIZATION",
  "room":"A101",
  "period_start":"2026-10-10T00:00:00.000Z",
  "period_end":"2026-10-16T23:59:59.999Z",
  "summary":{"incident_count":3},
  "recommendation":"Kiểm tra bộ điều khiển đèn sau các lần mất kết nối lặp lại."
}
```
